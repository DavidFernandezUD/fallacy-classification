### Descarga del modelo Word2Vec GoogleNews
Debido a restricciones de licencia, el archivo `GoogleNews-vectors-negative300.bin.gz`
no puede ser distribuido con el repositorio.

Descárgalo manualmente desde:

https://gitlab.com/nunet/fake-news-detection/data-storage/-/blob/master/GoogleNews-vectors-negative300.bin.gz?ref_type=heads

Una vez descargado, colócalo en:

./models/GoogleNews-vectors-negative300.bin.gz
